1. 是否達成 PR 說明與 `docs/plans/` 規劃文件中的每一條驗收條件
2. 測試是否真的驗證到驗收條件
3. Firestore 舊資料相容、AI API 失敗處理、金鑰安全、iOS Safari 相容性
