## 背景與使用情境
`interleaveByKey` 用於練習時把不同組別的句子交錯排列，避免同組句子連續出現。
現有測試涵蓋「不遺漏／不重複」「相鄰不同組」「避開 initialLastKey」，尚未涵蓋空陣列、只有一組、輸入不被修改等邊界。

## 相關檔案
- `src/utils/interleave.ts`
- `tests/patterns.test.ts`

## 做法
在 `tests/patterns.test.ts` 的 `describe('interleaveByKey')` 中新增測試：
1. 空陣列 → 回傳空陣列
2. 只有一組 → 回傳全部項目（無法避免相鄰同組，但不能遺漏）
3. 呼叫後原本的 `items` 陣列內容與順序不變

## 驗收條件
1. 空陣列 → `[]`（✅ 自動測試）
2. 只有一組的 5 個項目 → 回傳 5 個、內容相同（✅ 自動測試）
3. 呼叫前後 `items` 相同（✅ 自動測試）
4. `bash scripts/check.sh` 通過、測試數量增加（✅ PR 驗證＋防作弊檢查）
5. 預覽網站能開啟並用 GitHub 登入（👀 手動試用）
