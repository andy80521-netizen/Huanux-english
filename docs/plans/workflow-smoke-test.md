## 背景與使用情境
`interleaveByKey` 用於練習時把不同組別的句子交錯排列，避免同組句子連續出現。
現有測試涵蓋「不遺漏／不重複」「相鄰不同組」「避開 initialLastKey」，尚未涵蓋空陣列、只有一組、輸入不被修改等邊界。

## 相關檔案
- `src/utils/interleave.ts`
- `tests/patterns.test.ts`

## 做法
在 `tests/patterns.test.ts` 的 `describe('interleaveByKey')` 中新增測試：
1. 空陣列 → 回傳空陣列
2. 只有一組 → 回傳全部項目（無法避免相鄰同組，但不能遺漏）
3. 呼叫後原本的 `items` 陣列內容與順序不變

## 驗收條件
1. 空的 `string[]`（含 `initialLastKey='a'`）→ `[]`（✅ 空陣列回傳空陣列）
2. 同一組的 5 個項目，`initialLastKey` 為 null 或該組 → 回傳 5 個、排序後相同、不丟例外（✅ 只有一組時回傳全部項目）
3. 句子物件陣列呼叫後 → 原陣列順序、欄位、物件參考不變；回傳同一批物件（✅ 不會修改傳入的陣列與物件）
4. `bash scripts/check.sh` 通過；`describe('interleaveByKey')` 相對 main 新增 3 個 `it`，既有 `it` 未刪改（✅ PR 驗證＋防作弊檢查）
5. **流程實測**：委員會 5 位成員逐一有非空、非錯誤的回覆；Claude 的 `@codex` 留言觸發了 Codex 並產生審查結果（👀 Claude 逐一核對 PR 留言，結果寫進進度紀錄；成員失敗不算通過，只記錄原因）
