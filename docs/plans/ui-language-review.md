## 目標
把「語言模型」分頁每天使用的流程改成 A「靜讀」設計（設計稿已經擁有者確認），評分、熟練度、維持複習的規則與資料都不變。

2. **今日複習**（`TodayReviewView`）
   - 標題「今日複習」＋一行統計（文字不變）
   - 維持複習卡（金色盾牌圖示、金色淡邊框）：句型用襯線大字，下一行「維持題 N 句・已連續通過 N 次・3 句中 2 句全對即通過」

   - 卡片改成真正的 `<button>`（現在是可點的 div，鍵盤選不到）
   - 桌機：組別卡兩欄，右側欄放維持複習
3. **念出來練習**（`PatternPracticeSessionView`）
   - 頁首：返回＋「念出來練習」＋進度文字，下方細進度線（依 `progressLabel` 之外新增的可選 `progress` 數值）
   - 題目：小標（回答這個問題／情境任務／看圖說出對應的句子）＋題目襯線大字（看圖題為圓角圖片）＋「播放題目」外框按鈕
   - 待錄音：熟練度數值與進度條＋提示「說出你造的那句話，一字不差才算數」；底部大圓錄音鈕＋「換一組題目」

   - **評分結果**：大號襯線總分（一字不差時「總分・一字不差」並有金色小星點）、內容／流暢兩條細進度條；字不一致時 warn 提示「有 N 個字不一致，熟練度未增加」；**熟練度卡：本次增加量以金色「+N」與金色段顯示並跑動**（同跟讀）；目標原句（襯線）＋重播正確答案；您念的內容＋逐字比對（`WordDiffView`）＋重播我的錄音；「已到目前階段練習上限」提示；底部「再念一次／下一句（完成練習）」
   - 桌機（容器夠寬時）：左欄題目與目標原句、右欄評分結果；在 ③b 尚未改版的窄頁面中使用時維持單欄（用 container query 判斷，不看視窗寬度）
4. **完成畫面**（`TodayReviewView` 的兩種總結）
   - 本組練習完成：「第 N 組」＋標題＋句型；**本組 10 根大長條**，這次增加的熟練度以金色疊在上方（長條長高的動畫，減少動態效果時直接顯示）；練習句數／熟練度合計（金色）／本次精熟三格；「返回今日複習」
   - 維持複習結果：通過（金色盾牌）／沒通過（warn）／不計算／已更新／失敗，文字全部沿用

## 做法

### 1. 新增純函式 `src/utils/groupMastery.ts`
`groupMasteryBars(sentences, groupIndex, startMastery?)` → 長度固定 10 的陣列，第 i 格對應 id `p_<組>_<i>`（與 `GroupDetailView` 相同的編號規則）：
- `{ id, created, mastery, gain, mastered }`
- `created`：該句存在且 `checked`；沒造句的格子 `mastery` 0、`gain` 0
- `mastery`：夾在 0～1000；`mastered`：≥1000
- `gain`：有傳 `startMastery[id]` 時為 `max(0, mastery − start)`，沒傳為 0（完成畫面用；只算增加、不顯示減少）
- 其他組的句子、id 不符規則的句子忽略

### 2. 本次增加量（念出來練習）
在 `runScoring` 既有的 `updatePatternSentences` 更新函式裡，把舊熟練度一起放進 `outcome`（**只是多記一個值給畫面用**），結果畫面顯示 `newMastery − oldMastery`。不改 `calculateMasteryAfterAttempt`、不改寫入內容、不改一字不差才累加的規則。字不一致時不顯示增加量（沿用現有提示）。

### 3. 動效
- 總分與熟練度增加量沿用 `countUpValue` 跑動（同 ②a 跟讀），減少動態效果時直接顯示
- 完成畫面長條：長高動畫只在第一次出現時；減少動態效果時直接顯示
- 練習中不加任何新動畫（藍圖：練習時克制）

### 4. 共用
- 這 3 個元件不再使用 `slate-`、`indigo-`、`red-`、`emerald-`、`amber-`、`green-`、`orange-`、`yellow-`、`purple-` 色階 class
- 不改任何 handler、狀態流轉、Firestore 讀寫、AI 呼叫、評分與熟練度規則、維持複習規則

## 手動試用步驟
1. 預覽網站用 **Email 測試帳號**登入（連正式 Firebase；練習會產生 Whisper 費用、會改動測試帳號的熟練度）
2. 語言模型 → 今日複習：看組別卡的 10 根小長條是否對得上該組的熟練度
3. 點一組 → 念出來練習：分別遇到問答、情境、看圖題；一題念對、一題故意念錯一個字，看兩種結果畫面
4. 練完一組看「本組練習完成」；如有到期的維持複習也做一次
5. 桌機與手機、淺色與深色各看一次；系統開啟「減少動態效果」再看一次結果畫面
