# 規劃：語言模型練習的出題方式重新設計

- **級別**：大（重要 AI 提示詞；可能新增句子欄位、重新產生既有題目）
- **PR**：#（開 PR 後補上）
- **狀態**：規劃中

## 目標
讓「念出來練習」的題目**真的能引導使用者說出那一句**，並且有效訓練口說：使用者看到題目 → 能在腦中組出原句 → 說出來 → 評分。題目不能讓人「照題目回答卻被判錯」。

## 背景與使用情境（擁有者 2026-10-31 回報）
- 原句（使用者自己造的）：`All that she wrote will be published.`（句型 all that …）
- 題目（問答題）：「如果一本書的所有內容都將被公開發表，你會怎麼說這件事？」
- 結果：內容 0 分、7 個字不一致。使用者照題目情境回答，跟原句完全對不上；題目裡沒有「她」「寫」，主詞變成「一本書」
- 擁有者：題目很難融入情境，要重新檢討出題方式，研究怎樣有效讓使用者應用句子、達到口說進步

## 現況分析（Claude 對照程式碼）
1. **出題提示詞資訊不足**（`netlify/shared/prompts.ts` `buildPracticePromptsPrompt`）：只給英文原句和句型，要求「回答這個問句最自然的答案就是原句」。沒有要求題目保留原句的**所有資訊**（誰、做了什麼、時態、語氣），AI 為了讓問題聽起來自然，會改主詞、省略細節
2. **題型和評分互相矛盾**：評分是「精準背出原句」（`compareWords`，`errors === 0` 才累加），但「回答問題」「情境任務」天生有很多種正確答法（例如 It will all be published）。使用者越認真融入情境，越可能被判錯
3. **語言沒有規定**：提示詞沒說題目用中文還是英文；畫面卻把問答題當英文顯示（`lang="en"`、英文襯線大字）
4. **沒有品質檢查**：產生後直接存進句子（`qaQuestion`、`situationalPrompt`），之後永久重複使用；壞題目只能靠手動「換一組題目」
5. **沒有中文意思**：使用者自己造的句子（`PatternExampleSentence`）沒有存中文翻譯，題目是唯一線索
6. **看圖題同樣有問題**：圖片很難表達「她寫的」「將會出版」這類資訊；熟練度高時看圖題比例最高（45%）
7. 出題模型：`callQualityText`，溫度 0.3

## 學習原理（設計依據，請委員補充或反駁）
- **主動回想（retrieval practice）**：自己想出來比重看一遍記得牢；但前提是**線索足以想出答案**，想不出來的回想沒有效果
- **漸進撤除提示（fading cues）**：一開始給完整線索（中文全意），熟了之後只給部分線索（情境＋關鍵字），最後只給情境
- **輸出假說（output hypothesis）**：被迫說出完整句子，才會發現自己不會的地方
- **遷移（transfer）**：只背固定句，換個情境可能就說不出來；能把句型用在新內容，才是「會用」

## 做法（草案，請委員評估）
### 方向 A：保留「精準背出原句」，題目改成「足以還原原句」的線索（建議）
- 題目一律用**中文**，結構固定：
  - 情境（一句：在哪裡、對誰說）
  - 你想表達的意思（中文，**涵蓋原句每一個資訊**：主詞、動作、時態、否定、數量…）
  - 標示要用的句型（例如「用 all that …」）
- 依熟練度漸進撤除提示：
  | 熟練度 | 題型 | 給什麼 |
  |---|---|---|
  | < 400 | 中文全意 | 情境＋完整中文意思＋句型 |
  | 400～699 | 情境＋關鍵字 | 情境＋中文意思（不給句型） |
  | ≥ 700 | 對話接龍／看圖 | 對方說的一句話或圖片＋情境，答案仍是原句（這時已熟記，線索只需能聯想到這一句） |
- 新增句子的中文翻譯欄位（例如 `meaningZh`），出題時一起產生、題目畫面可選擇顯示
- **品質檢查**：產生後由另一次 AI 呼叫「只看題目，說出英文句子」，用 `compareWords` 比對原句；差太多就重新產生（最多 N 次）
- 既有題目：加版本欄位，練習時發現是舊版就重新產生（**會改寫既有題目資料，需擁有者同意**）

### 方向 B：加入「應用」練習（遷移）
- 精熟後的句子（或句型）出現「換個情境用這個句型說」：AI 給新情境，使用者自由造句說出，AI 評估句型用得對不對、說得自然不自然
- 不計入熟練度（熟練度只衡量背出原句），另外記錄
- 與「教材複述」「維持複習」的關係需要釐清

## 待委員會評估的問題
1. 方向 A 的題目結構和難度階梯是否合理？中文全意會不會讓練習變成「中翻英」而太簡單、或依然有多種譯法？
2. 品質檢查（AI 反向作答再比對）是否可靠？成本與延遲？
3. 看圖題是否應該只在高熟練度出現，或改成「圖片＋中文意思」？
4. 方向 B 是否值得做？和現有功能（複述、維持複習）重疊嗎？評分方式？
5. 既有句子的題目要不要全部重新產生？怎麼做才安全？
6. 有沒有更有效的口說訓練出題方式（請具體說明依據）？

## 驗收條件（初稿）
1. 出題提示詞要求題目涵蓋原句所有資訊、用中文、標示句型（✅ 提示詞測試）

3. 依熟練度選擇題型與提示多寡（✅ 單元測試）

5. 👀 用 10 句不同句型實際產生題目，人工檢查：每一題都能讓人唯一想到原句
